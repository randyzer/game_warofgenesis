Gear value is situational. The useful question is not “Is this item rare?” but “What would I lose by using, changing, or selling this item now?”

## Start with the exact item

Confirm the item type and the details shown in the current game and Steam interfaces. Check whether the specific copy is marketable rather than assuming that every item with the same name can be listed. If a detail is unclear, keep the item until you can verify it.

## Use the keep-or-sell sequence

1. **Check build fit.** Does the item improve the activity your current build is meant to handle?
2. **Check immediate usefulness.** Would equipping or keeping it remove a progression constraint now?
3. **Check replacement difficulty.** How costly would it be to regain the same role if you sell or consume it?
4. **Check progression options.** Compare equipping, keeping, upgrading, or synthesizing only where the current game interface confirms those actions for the item.
5. **Check market eligibility.** Use Steam's current interface for the exact copy.
6. **Compare the trade-off.** Estimate Wallet proceeds, then decide whether those proceeds outweigh the item's progression value.

Rarity alone does not answer any of these questions. It can tell you to slow down and inspect an item, but it does not prove build fit, demand, eligibility, or replacement cost.

## Keep when progression value is clearer

Keeping is the safer choice when the item supports a current goal, protects a reliable farming setup, or would be difficult to replace with what you can access now. Keep a stable equipment baseline while testing one change at a time.

If the item changes what your setup can clear reliably, revisit the [Builds decision guide](/builds/) and compare the result with the [Farming Guide](/guides/farming/).

## Consider selling when the trade-off is understood

A marketable item deserves a manual check when it is not solving a near-term progression problem and you understand what giving it up would cost. A visible listing is not proof of demand or a completed sale, and this wiki does not publish live prices.

Use the [Best Items to Sell framework](/market/best-items-to-sell/) to decide what deserves attention. Then read the [Steam Market Guide](/market/) and use the [fee calculator](/tools/steam-market-fee-calculator/) before confirming a listing.

## Record enough to revisit the decision

For uncertain items, note the build goal, the role the item could fill, what would replace it, and why you kept or sold it. Recheck after a meaningful gear, build, or progression change instead of treating the first decision as permanent.

## Your next decision

If the item is part of a farming goal, compare it against your reliable setup in the [Farming Guide](/guides/farming/). If it is a genuine sale candidate, continue with the [Best Items to Sell framework](/market/best-items-to-sell/).
