War of Genesis: Idle Loot の Profile アイコンは左上にあり、公式サポートはクリックすると User Code が表示されると説明しています。10月7日のアップデートでは、現在のキャラクターと装備中のスキンを反映したプロフィール画像が追加されました。フレームには別のショップの手順があります：Skin → Frame → Frame Shop。

<h2 id="user-code">サポートが求める User Code を確認する</h2>

公式サポートフォームは、User Code を確認する場所として左上の Profile アイコンを明示しています。サポートへの問い合わせを準備する際は、ゲーム内でそのアイコンを開き、識別子を確認してください。

これはゲーム内サポートの識別子であり、Steam アカウントのプロフィールを別の名前で呼んでいるわけではありません。提供されたフォームは項目の場所を裏付けますが、追加のアカウント連携メニューや、完全なアカウント復旧手順は確認できません。

<h2 id="images">10月7日のアップデートのプロフィール画像</h2>

正式リリースのアップデートでは、現在のキャラクターと装備中のスキンに連動するプロフィール画像が導入されています。これにより、プロフィール画像がキャラクターの着用物と結びついている理由が説明できます。

提供されたアップデートには、確認済みのカスタム画像アップロード手順はありません。そのため、この資料ではキャラクターとスキンの説明に従い、裏付けのないアップロードボタンやアバター編集オプションの一覧は追加していません。

<h2 id="frames">Frame Shop を見つける</h2>

10月7日の告知は、フレームを購入する手順を Skin → Frame → Frame Shop と示しています。記載された入口としてこの手順を使い、その後の画面変更は現在のクライアントで確認してください。

価格、フレームの完全な一覧、購入の前提条件は、この資料では確認できないため省略しています。[ゲーム内購入](/guides/in-app-purchases/)は、別途確認された G-Coins と Shop の情報を扱っています。すべての装飾品が同じ購入ルールを使うとは仮定していません。

<h2 id="official-support">公式サポートの資料を使う</h2>

元の[公式問い合わせフォーム](https://genesis-idleloot.zendesk.com/hc/en-us/requests/new)に Profile/User Code の入口が記載されています。[公式ニュースページ](https://steamcommunity.com/app/4891320/allnews/)は、日付付きのプロフィール画像とフレーム変更の出典です。

調査の最終確認日は2026年10月10日です。これらの公式ページは記載した項目と画面上の手順を裏付けていますが、プロフィールのカスタマイズを追加で実機検証したわけではありません。
