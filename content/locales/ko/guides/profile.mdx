War of Genesis: Idle Loot의 Profile 아이콘은 왼쪽 위에 있으며, 공식 고객 지원은 이를 클릭하면 User Code를 볼 수 있다고 안내합니다. 10월 7일 업데이트는 현재 캐릭터와 장착한 스킨을 반영하는 프로필 이미지를 추가했습니다. 프레임은 별도 상점 경로인 Skin → Frame → Frame Shop에서 확인합니다.

<h2 id="user-code">고객 지원에서 요청하는 User Code 찾기</h2>

공식 고객 지원 양식은 User Code를 볼 수 있는 위치로 왼쪽 위 Profile 아이콘을 명시합니다. 고객 지원 요청을 준비할 때 게임에서 해당 아이콘을 열어 식별자를 확인하세요.

이는 게임 내 고객 지원용 식별자이며 Steam 계정 프로필을 대신하는 이름이 아닙니다. 제공된 양식은 해당 필드의 위치를 뒷받침하지만, 추가 계정 연동 메뉴나 완전한 계정 복구 절차까지 확인해 주지는 않습니다.

<h2 id="images">10월 7일 업데이트의 프로필 이미지</h2>

정식 출시 업데이트는 현재 캐릭터와 장착한 스킨에 연동되는 프로필 이미지를 도입했습니다. 따라서 프로필 이미지가 캐릭터의 착용 상태와 연결되는 이유를 알 수 있습니다.

제공된 업데이트에는 검증된 사용자 이미지 업로드 절차가 없습니다. 이 자료는 캐릭터와 스킨에 관한 설명을 따르며, 근거 없는 업로드 버튼이나 아바타 편집 옵션 목록을 추가하지 않습니다.

<h2 id="frames">Frame Shop 위치 찾기</h2>

10월 7일 공지는 프레임 구매 경로로 Skin → Frame → Frame Shop을 안내합니다. 이를 문서에 명시된 진입 경로로 참고하되, 이후 인터페이스 변경이 있었는지는 현재 클라이언트에서 확인하세요.

가격, 전체 프레임 목록, 구매 조건은 이 자료에서 확인되지 않아 생략합니다. [게임 내 구매](/guides/in-app-purchases/)는 별도로 확인된 G-Coins와 Shop 정보를 다루며, 모든 꾸미기 아이템의 구매 규칙이 같다고 가정하지 않습니다.

<h2 id="official-support">공식 고객 지원 자료 이용하기</h2>

원래의 [공식 요청 양식](https://genesis-idleloot.zendesk.com/hc/en-us/requests/new)은 Profile/User Code 항목을 설명합니다. 날짜가 명시된 프로필 이미지와 프레임 변경 사항은 [공식 소식 페이지](https://steamcommunity.com/app/4891320/allnews/)에서 확인할 수 있습니다.

조사 최종 확인일은 2026년 10월 10일입니다. 이 공식 페이지들이 설명된 필드와 인터페이스 경로를 뒷받침하며, 추가적인 프로필 꾸미기 실사용 테스트는 수행하지 않았습니다.
