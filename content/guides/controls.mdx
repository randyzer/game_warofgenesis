The Codex overlay is designed to answer a question and then get out of the mine's way. A useful layout shows the active crew, the current objective, and urgent warnings without turning the screen into a dashboard. Configure it after a short expedition, when you know which details you actually reach for.

<h2 id="pointer-controls">Pointer controls</h2>

Select a crew portrait to open its compact card; select it again to expand equipment and conditions. Drag an empty part of any panel header to move that panel. The body remains interactive, so dragging from a button or link performs that control's action instead. Use the corner grip to resize and the top-right mark to collapse.

On the map, select a chamber to view its forecast. Hold the pointer over an icon for a plain-language explanation, including whether the value is known or estimated. Secondary-select a chamber to pin it as the working objective. Secondary-select the pin again to remove it. The overlay never sends a crew by itself; route confirmation still happens at the Gatehouse.

<h2 id="keyboard-controls">Keyboard controls</h2>

Press `C` to show or hide the Codex, `M` to focus the route map, and `R` to open the current crew's Resolve history. Number keys one through three switch between crew summaries. When a panel has focus, use arrow keys to move among controls, Enter to activate, and Escape to return focus to the expedition.

Hold Shift while pressing an arrow key to move a floating panel in small steps. This is useful when a border hides an exit marker. Keyboard shortcuts pause while a text note is active, so typing a route name never triggers a panel. The shortcuts are reminders, not requirements; every action also has a visible pointer control.

<h2 id="pin-and-resize">Pin and resize</h2>

Pin only information that changes a decision. Good candidates are a retreat threshold, the next hazard, or a material target. A complete inventory rarely deserves permanent space. Resize the crew panel until four conditions fit without scrolling, then collapse secondary details. On a narrow display, stack the objective above the crew strip instead of placing two panels side by side.

Layouts save automatically per display size. If you move between a large monitor and a handheld screen, each keeps its own arrangement. Start from [Getting Started](/guides/getting-started/) if you want a minimal first-session setup, and reset the layout whenever accumulated tweaks become harder to understand than the default.
