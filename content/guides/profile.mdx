The War of Genesis: Idle Loot profile icon is in the upper-left corner, and official support says clicking it reveals your User Code. The October 7 update adds profile images reflecting the current character and equipped skin. Frames have a separate shop path: Skin → Frame → Frame Shop.

<h2 id="user-code">Find the User Code requested by support</h2>

The official support form explicitly identifies the upper-left Profile icon as the place to view a User Code. Open that icon in the game to locate the identifier when preparing a support request.

This is an in-game support identifier, not a replacement name for a Steam account profile. The supplied form supports the location of the field; it does not establish additional account-linking menus or a full account-recovery process.

<h2 id="images">Profile images in the October 7 update</h2>

The release update introduces profile images linked to the current character and equipped skin. That explains why the profile image is connected to what the character is wearing.

The supplied update does not provide a verified custom-image upload process. This reference therefore follows the character-and-skin description without adding an unsupported upload button or list of avatar-editing options.

<h2 id="frames">Locate the Frame Shop</h2>

The October 7 announcement gives the path Skin → Frame → Frame Shop for purchasing frames. Use that path as the documented entry, while checking the current client for any later interface changes.

Prices, the complete frame catalog, and purchase prerequisites are not established by this material and are omitted. [In-app purchases](/guides/in-app-purchases/) covers the separately confirmed G-Coins and Shop information, without assuming that every cosmetic uses identical purchase rules.

<h2 id="official-support">Use the official support reference</h2>

The original [official request form](https://genesis-idleloot.zendesk.com/hc/en-us/requests/new) documents the Profile/User Code entry. The [official news page](https://steamcommunity.com/app/4891320/allnews/) provides the dated profile-image and frame changes.

Research last checked October 10, 2026. These official pages support the stated fields and interface paths; no additional hands-on profile customization test was performed.
